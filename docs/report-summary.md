# Report Summary

`usdopt report-summary` summarizes optimization report JSON files generated by `usdopt optimize` and `usdopt smoke-test`.

## Text summary

```powershell
uv run usdopt report-summary --reports-dir reports/smoke-tests
```

The text table shows:

- status;
- preset name;
- duration;
- output file size;
- operation count;
- warning count;
- error count;
- output path relative to the reports directory.

This is useful after external asset smoke tests because repeated filenames such as `HelloWorld.usda` appear in multiple OpenUSD tutorial folders.

## JSON summary

```powershell
uv run usdopt report-summary --reports-dir reports/smoke-tests --json
```

The JSON output is intended for later automation and comparison between presets.
Read-only analysis profiles still write a report JSON, including their `operation_results`,
but intentionally do not write the USD output path shown in the table. A `missing` size is
therefore expected for those entries.
